### 🧭 What we do

From full-stack development to penetration testing — we engineer resilient
software and fortify the infrastructure it runs on. Every product we ship is
**privacy-first by design**: minimal data collection, end-to-end encryption
where applicable, and source code that's available to read.

#### 🌐 Web Applications
Production-grade platforms built to scale.

- Server-rendered & single-page applications
- Real-time data systems with WebSocket / SSE
- RESTful & GraphQL API architecture
- Authentication, RBAC, session management
- Database design, migration, optimisation
- CI/CD pipelines and deployment automation

#### 📱 Mobile Applications
Native performance, offline-first reliability.

- Native Android (Kotlin / Java) and iOS (Swift)
- Cross-platform with React Native (Expo)
- Offline-first architecture with local sync
- Push notifications & background services
- App Store / Play Store compliance & deployment
- Performance profiling & battery optimisation

#### 🛡️ Security Testing
Find vulnerabilities before attackers do.

- OWASP Top 10 vulnerability assessment
- API security testing, fuzzing, abuse testing
- Authentication & session management review
- Source-code review & static analysis (SAST)
- Infrastructure & configuration audit
- Compliance-oriented testing (PCI DSS, GDPR, SOC 2)

#### ⚔️ Penetration Testing
Real adversarial simulation, not automated reports.

- External & internal network pentesting
- Web and mobile application pentesting
- Social engineering & phishing assessments
- Wireless network security testing
- Red team / adversary simulation
- Detailed reports with exploitation proof + fix guidance

### 🔐 How we work

- **Open source where possible** — auditable code beats a privacy promise
- **Zero unnecessary data** — collect what's strictly required, log nothing else
- **End-to-end encryption** when peers exchange data we don't need to see
- **Hardware-backed keys** when the platform supports them
- **Documented threat models** for every product
